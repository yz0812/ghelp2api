# 链路编排验收计划

日期：2026-11-17。目标版本：v1.3.0。授权范围：本地实施、oracle1 部署和自验收。

## 放行条件

必须通过本地自动化、固定 Mihomo 真实转发、ARM64、生产副本迁移与恢复、正式域名和外网转发验收。生产至少观察 15 分钟，完成容器重建回归和验收资源清理。不能用健康接口代替业务转发测试。

| 编号 | 场景与操作 | 通过标准 | 验证位置 |
|---|---|---|---|
| A01 | 将旧数据库从 0011 升级至 0012 | 原有字段、认证密文、订阅引用不变；旧监控默认关闭；完整性通过 | oracle1 独立副本 |
| A02 | 完整卷备份恢复至旧镜像 | UID 10001 可以启动；迁移版本 0011；健康、完整性通过 | 独立恢复卷和容器 |
| A03 | 编排 2／3／5 跳，访问受控目标 | 每跳均实际经过，原生导出和服务器中转成功 | Windows 与 ARM64 真内核 |
| A04 | 断开末跳 | 转发失败，不绕过到直连 | 真内核测试 |
| A05 | 调整候选快慢、容差和可用性 | 最快择优；容差内不切换、超过才切换；指定入口不替换；主备故障切换及恢复回切 | 真内核测试 |
| A06 | 添加中间跳、复制主备、换序 | 顺序保存回显；首尾固定位置；最多五跳、三条路径 | API 与浏览器 |
| A07 | 失效引用、重复节点、UDP 后续跳、锁出口 | 明确拒绝；失效主路径可退备用；被引用资源受删除保护 | API |
| A08 | 同一版本并发编辑及模拟校验失败 | 一次成功、一次 409；监控能同时写入；失败不改变旧配置 | API 并发测试 |
| A09 | 草稿诊断 | 独立内核；累计前缀和出口 IP；线上 revision 和实际选路不变 | 真内核、正式服务器 |
| A10 | 五项诊断同时排队、超时、立即取消 | 最大并发二；超时为未知；取消正确终态；临时内核清理 | API 与任务测试 |
| A11 | 自动监控与历史 | 定时产生样本；明确监控结果才计可用率；缺测不算成功；30 天过期清理 | 调度、历史 API、线上观察 |
| A12 | 故障、恢复、切换、IP 变化 | 对应事件可查；配置路径与运行路径分别展示 | API 与线上故障演练 |
| A13 | 模板保存、套用、编辑、删除 | 只有引用与策略；无认证、端口、历史；失效引用提示 | API 与浏览器 |
| A14 | 克隆、批量启停／检测／监控／删除 | 克隆新认证与端口且停用；逐项报告部分失败 | API 与浏览器 |
| A15 | 新建／合入订阅、原生多跳导出 | 引用保留、拨号顺序有效、受保护订阅不误删 | API、旧界面回归、线上导出 |
| A16 | 内联创建资源、离开草稿、键盘操作 | 新资源可选并持久化；离开提醒；取消保留草稿；键盘可保存 | 浏览器 |
| A17 | 320／390／768／1440，深浅主题 | 无页面横向溢出，控件可操作，诊断与历史可用 | 本地和正式域名 |
| A18 | 从本地访问服务器 20000／20001 | 原链路和验收链路 HTTP、HTTPS CONNECT 均成功；认证不变 | 独立于服务器的外网请求 |
| A19 | 仅中断临时验收入口再恢复 | 自动退备用，备用转发成功，恢复后回主路径；原链路不受影响 | oracle1 |
| A20 | 观察、重建与清理 | 15 分钟持续健康、零异常重启；重建后配置保留；精确清理验收 ID 和会话 | oracle1 |

## 执行与恢复

- 先完成只读检查、构建和独立副本演练，再切换正式服务。
- 发布前停止应用，备份完整数据卷、Compose、环境文件和旧镜像；备份留在服务器受限目录。
- 本次仅重建 ghelper。端口映射与应用默认 20000–20099 一致，以实际外网转发验证防火墙效果。
- 关键业务回归失败时同时恢复旧镜像、完整卷和 Compose；恢复后校正数据属主为 UID/GID 10001。
- 临时会话只用于本次验收，验收完成后撤销；报告不得包含密码、密钥或订阅密钥。
